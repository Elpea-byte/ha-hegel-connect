# Security

Hegel Connect only talks to your amplifier on your own network; it has no cloud part and stores no passwords.

Known limitation: the amplifier's local API has no authentication. Hegel Connect only accepts a new address after the device there reports your amplifier's id, but a device that imitates the complete Hegel API on your network cannot be detected.

If you find a security problem, please **do not open a public issue**. Report it privately via *Security > Report a vulnerability* on this repository. You will get an answer within a week.
